# CharchaDesk 

A real-time chat application built with Django and WebSockets.

## Features
- Real-time messaging
- Typing indicator
- Online/Offline status
- Read receipts 
- Notifications

## Upcoming AI Features
- Smart Reply Suggestions
- Chat Summarization
- Emotion Detection

## Tech Stack
- Django
- Django Channels
- PostgreSQL
- Tailwind CSS
- JavaScript

## Setup
git clone <repo-url>
cd charchadesk
pip install -r requirements.txt
